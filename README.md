# Purvi — Public Policy Portfolio

A multi-page portfolio for a public policy and international relations professional. The site combines a forest, mint and sand visual system with a WebGL geopolitical map and dedicated pages for Purvi’s profile, policy work, writings, CV and contact details.

## Pages

- `/` — interactive geopolitical portfolio hero
- `/about` — profile, approach and areas of inquiry
- `/work` — policy research and project case-study structure
- `/writings` — essays, analysis and research notes
- `/writings/:slug` — long-form article layout
- `/cv` — responsive web CV with print-to-PDF support
- `/contact` — contact details and inquiry form structure

Unconfirmed credentials, projects and publications are represented as explicit editable placeholders rather than invented information.

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — type-check and create a production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build

## Ponytail

The official [`@dietrichgebert/ponytail`](https://www.npmjs.com/package/@dietrichgebert/ponytail) package is installed as a development dependency, as requested. It is an AI-agent development aid rather than a browser runtime dependency.
