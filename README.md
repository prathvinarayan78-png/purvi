# Purvi — Policy Portfolio Hero

A vibrant, interactive portfolio hero for a public policy and international relations professional. The design pairs an editorial light-mode aesthetic with a true WebGL policy globe, animated diplomatic routes, interactive regional nodes, and responsive geopolitical focus controls.

## Run locally

```bash
npm install
npm run dev
```

The site is built with React, TypeScript and Vite.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — type-check and create a production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build

## Ponytail

The official [`@dietrichgebert/ponytail`](https://www.npmjs.com/package/@dietrichgebert/ponytail) package is installed as a development dependency, as requested. It is an AI-agent development aid rather than a browser runtime dependency.
